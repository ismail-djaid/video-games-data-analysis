# 🎮 Анализ продаж видеоигр

## 📌 О проекте

Комплексный проект по анализу данных о мировых продажах видеоигр.

Проект демонстрирует полный цикл работы с данными с использованием **Python, PostgreSQL и Power BI** — от очистки и исследовательского анализа данных до SQL-анализа и создания интерактивного дашборда.

Основная цель проекта — исследовать рынок видеоигр, выявить основные тенденции и проанализировать продажи по платформам, жанрам, регионам и годам.

## 🗄 SQL-анализ

PostgreSQL использовался для выполнения аналитических запросов по данным о видеоиграх.

В рамках SQL-анализа выполнены:

- расчёт общего объёма и средних продаж;
- анализ продаж по жанрам;
- определение наиболее успешных платформ;
- поиск самых продаваемых игр;
- анализ издателей;
- фильтрация агрегированных данных с помощью `HAVING`;
- сегментация игр с помощью `CASE`;
- ранжирование игр внутри жанров с использованием оконных функций.

### Использованные возможности SQL:

`SELECT` `WHERE` `GROUP BY` `ORDER BY` `HAVING` `CASE WHEN`  
`COUNT` `SUM` `AVG` `Subqueries` `ROW_NUMBER()` `PARTITION BY` `Window Functions`

## 🔎 Основные выводы

По результатам анализа были выявлены следующие тенденции:

- рынок видеоигр значительно вырос в 2000-х годах и достиг наиболее высоких объёмов продаж в конце 2000-х;
- жанр Action занимает одну из ведущих позиций по глобальным продажам;
- предпочтения игроков различаются между рынками Северной Америки, Европы и Японии;
- значительная доля продаж приходится на ограниченное количество наиболее популярных платформ;
- популярность платформ и жанров существенно менялась в разные периоды.
