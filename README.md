# 🎮 Video Games Sales Analysis

## 📌 О проекте

Проект посвящён анализу данных о продажах видеоигр.
Цель — исследовать рынок видеоигр и определить основные тенденции продаж по платформам, жанрам, регионам и годам.

## 🛠 Используемые инструменты

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Датасет

В проекте используется датасет, содержащий около 17 000 записей о видеоиграх.

Основные данные:
- название игры
- платформа
- жанр
- год выпуска
- издатель
- продажи в Северной Америке
- продажи в Европе
- продажи в Японии
- глобальные продажи
- оценки критиков и пользователей

## 🔎 Этапы анализа

1. Загрузка и изучение данных
2. Проверка типов данных
3. Поиск и обработка пропущенных значений
4. Очистка данных
5. Исследовательский анализ данных (EDA)
6. Анализ продаж по регионам
7. Анализ платформ и жанров
8. Анализ динамики продаж по годам
9. Визуализация результатов
10. Формирование выводов

## 💡 Навыки, продемонстрированные в проекте

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Pandas
- NumPy
- Data Visualization
- Работа с пропущенными значениями
- Группировка и агрегация данных
- Анализ бизнес-метрик
- Формирование выводов на основе данных
